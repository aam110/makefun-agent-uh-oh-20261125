Entry for the make.fun bounty [The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4): one word an agent says when it has no idea what to do, written by `main.ts` to `entry.txt`.

The word is "Adjourned" — when the agent is lost, it does not panic, stall, or confess. It bangs the gavel, closes the proceedings, and goes home: a courtroom word from a machine that has run out of answers.
